AI Content Agent - Website Planning Update

This is a six-file update package. Copy these files into the ROOT of your existing AI Content Agent project, replacing files with the same names. Do not replace your whole project folder. Preserve your .env, Firebase service account credentials, node_modules, and local data.

Files: chat.js, index.html, server.js, website-builder-client.js, website-builder.js, website-planning.js

After copying, run: node --check .\chat.js ; node --check .\server.js ; node --check .\website-builder-client.js ; node --check .\website-builder.js ; node --check .\website-planning.js
Then restart local server with: node .\server.js
